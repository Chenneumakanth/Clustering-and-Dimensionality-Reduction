# Assignment 08 – Clustering and Dimensionality Reduction

## 📌 Project Overview
This project focuses on customer segmentation using clustering algorithms and dimensionality reduction techniques. The goal is to identify customer groups based on their income and spending patterns.

## 🎯 Objectives
- Analyze and understand customer data.
- Apply different clustering algorithms.
- Identify the optimal number of clusters using the Elbow Method.
- Reduce data dimensions using PCA and t-SNE.
- Visualize customer segments and interpret the results.

## 📊 Dataset
- **Dataset:** Mall Customer Spending Data
- **File:** `mall_customer_spend.xlsx`
- Contains customer details such as age, gender, annual income, and spending score.

## 🔄 Key Operations Performed

### 1. Data Exploration
- Loaded and explored the dataset.
- Checked data types and summary statistics.
- Examined the data for analysis.

### 2. Clustering
- Applied K-Means clustering.
- Used the Elbow Method to select the number of clusters.
- Performed Hierarchical Clustering and DBSCAN.
- Visualized customer groups.

### 3. Dimensionality Reduction
- Applied PCA to reduce the number of features.
- Used t-SNE to visualize customer patterns in lower dimensions.

### 4. Data Visualization
- Created visualizations to understand customer clusters.
- Compared patterns identified by different techniques.
